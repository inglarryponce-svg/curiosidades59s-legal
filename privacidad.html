Política de Privacidad

Aplica al proyecto "Curiosidades en 59 segundos" y a las integraciones que utiliza con las APIs de YouTube, TikTok, Meta (Facebook e Instagram) para publicar contenido de video.

1. Responsable

"Curiosidades en 59 segundos" es un proyecto personal operado por Larry Gamaliel Ponce Orenday. Para cualquier consulta sobre esta política o sobre el tratamiento de datos, podés escribir a curiosidadesen59s@gmail.com.

2. Alcance de esta política

Esta herramienta es de uso propio: automatiza la generación y publicación de video en las cuentas del propio proyecto (YouTube, TikTok, Instagram y Facebook creadas específicamente para "Curiosidades en 59 segundos"). No se ofrece como servicio a terceros ni permite que otras personas conecten sus propias cuentas. Si en el futuro esto cambiara, esta política se actualizaría antes de habilitar esa función.

3. Datos a los que se accede a través de las APIs de plataformas

Para publicar contenido de forma automatizada, el proyecto se conecta mediante OAuth a las cuentas propias en cada plataforma y accede únicamente a lo necesario para esa función:

  • TikTok (Content Posting API): identificador de la cuenta y datos básicos de perfil (nombre de usuario, foto) necesarios para autenticar la conexión, y los permisos requeridos para publicar (subir) videos en la cuenta conectada.
  • YouTube (YouTube Data API v3): acceso para subir videos y gestionar metadatos (título, descripción, miniatura) del canal propio.
  • Meta (Instagram Graph API): acceso a la Página de Facebook y a la cuenta de Instagram Business propias para publicar Reels.

El video que se publica y su metadata (título, descripción, hashtags) son generados por el propio proyecto antes de enviarse a cada plataforma vía su API.

4. Datos que este proyecto no recolecta

  • No se recolectan datos personales de las personas que ven, comentan o interactúan con los videos publicados (seguidores, espectadores, comentaristas).
  • No se accede a las listas de contactos, mensajes privados ni datos de otras cuentas de TikTok, YouTube, Instagram o Facebook distintas a las propias del proyecto.
  • No se recolecta información de menores de edad ni se dirige contenido específicamente a ellos.

5. Cómo se usa la información

Los tokens de acceso (OAuth) obtenidos de cada plataforma se usan exclusivamente para autenticar la publicación automatizada de video en las cuentas propias del proyecto. No se usan para ningún otro fin.

6. Almacenamiento y seguridad

Los tokens de acceso y credenciales se almacenan en la infraestructura local controlada por el operador del proyecto (entorno de automatización propio), y no se publican ni se comparten. Se toman medidas razonables para protegerlos de acceso no autorizado.

7. Compartición con terceros

No se venden ni se comparten datos de las cuentas de las plataformas con terceros. El proyecto puede usar servicios de generación de contenido (por ejemplo, modelos de lenguaje o de voz/imagen) para crear el guion, audio o visuales del video, pero estos servicios no reciben datos personales de TikTok, YouTube, Instagram ni Facebook — solo el contenido creativo que el propio proyecto genera para el video.

8. Retención y eliminación de datos

Los tokens de acceso se conservan mientras la automatización esté activa. Se pueden revocar en cualquier momento desde la configuración de apps conectadas de cada plataforma (por ejemplo, en TikTok: Configuración → Seguridad y permisos → Apps y servicios conectados). Al revocarse, este proyecto deja de tener acceso a la cuenta correspondiente.

9. Menores de edad

Este proyecto no está dirigido a menores de edad y no recolecta a sabiendas información de menores a través de las APIs que utiliza.

10. Cambios a esta política

Esta política puede actualizarse a medida que el proyecto evolucione (por ejemplo, si se agregan nuevas plataformas o funciones). La fecha de "Última actualización" al inicio de esta página refleja la versión vigente.

11. Contacto

Para preguntas sobre esta Política de Privacidad: curiosidadesen59s@gmail.com.
